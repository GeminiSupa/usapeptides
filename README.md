# usapeptides - Battle Born Peptides Clone

A high-performance research peptide e-commerce and laboratory reference platform built with **Next.js 14 App Router**, **TypeScript**, and **Tailwind CSS**.

## Features

- **Scientific Design & Identity**: Sleek dark navy theme matching Battle Born Peptides with Research Use Only compliance banners.
- **Product Catalog**: 30+ peptides spanning Incretins, GHRH/GHRP, ECM Repair, Melanocortins, Neuropeptides, Longevity & BAC Water.
- **HPLC / MS Certificate of Analysis (COA) Viewer**: Interactive modal displaying high-resolution simulated chromatograms and mass spectrometry scans.
- **Peptide Reconstitution Calculator**: Dynamic U-100 syringe visualization calculating units from mg, mL, and mcg.
- **Tiered Volume Pricing**: Automatic discounts (10% off 3-4, 15% off 5-9, 20% off 10+).
- **Cart Drawer & Checkout Flow**: Slide-out cart drawer, free shipping threshold meter (), coupon code system (RESEARCH10, USA20), and multi-step checkout.
